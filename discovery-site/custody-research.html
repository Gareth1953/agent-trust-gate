Custody separation, tested.

A compromised agent should not own the key and database that decide whether its authority has already been used. ATG’s optional service separates those roles and tests the boundary under actual Linux identities.

The architecture change

Separate ownership before stronger claims.

The writer holds the issuer’s public verification key. The agent holds a client credential and signed grant. The issuer’s private signing key stays outside both the agent and writer identities.

01

Protected issuer

A distinct issuer identity holds a fresh evaluation signing key. Approval evidence remains synthetic; real principal authentication is not established by this test.

02

Retained writer

A separate writer atomically records the synthetic effect and consumption. Pinned mutual TLS authenticates the endpoint and allowed client. No local fallback or automatic retry.

03

Untrusted agent

The tested agent could neither edit/copy writer state nor change trusted configuration/code. Copied credentials still reach the same retained one-use record.

One-use has a precise scope.

It is enforced across clients and restarts of one retained writer database. It is not a global guarantee across restored servers, other providers or real payment rails. No HSM or independently held anti-rollback checkpoint is implemented.
