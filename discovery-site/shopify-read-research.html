Controlled engineering evaluation · 27 October 2026

One authorised Shopify API read, with linked completion evidence.

ATG demonstrated one founder-approved, read-only Shopify development-store operation through a controlled gateway. This is a bounded engineering result, not production certification or Shopify endorsement.

Observed live operation

What was demonstrated

Authorised exact request

The unmodified MCP Python SDK 1.26.0 used a documented protocol pin to propose a fixed products.read_one action. ATG's local evaluation proof was checked before gateway admission.

Shopify connection

One token request returned HTTP 200 with exactly read_products; one products(first: 1) query returned HTTP 200 using Admin API 2026-10, with one product result.

Linked evidence

Eight MCP/gateway checks passed. A repeated submission was refused. Completion was recorded as READ_COMPLETED / SHOPIFY_RESPONSE_VALIDATED; local reconciliation made no second API request.

Boundaries and limitations

What this does not establish

The test did not use autonomous LLM inference, real customer transactions, live payments, order changes, checkout writes or merchant production systems. The public evaluation plugin does not contain the private Shopify connector. No independent Shopify-side packet accounting, security audit, production certification, commercial endorsement or partnership is claimed.

Security blockers remain: same-user credential and direct SQL bypass, cloned authority-state replay, lack of independently administered checkpoint custody and incomplete mediation across alternate routes. Signatures and same-host audit records do not independently prove a business effect.

Provenance disclosure: one earlier PI2 offline offline-results.json was accidentally overwritten, and the exact original has not been recovered. Its expected and replacement hashes are retained in the internal research packet. The separate live Shopify result has its own preserved, checked hashes; it does not resolve that historical incident.

ATG remains a development/evaluation technology. Production use is NO-GO pending hardened enforcement, independent assessment and customer-controlled operational qualification.
