# Buyer diligence and bounded evaluation proposal

## Proposition

ATG offers an inspectable exact-action authority evaluation core and integration
research. A prospective buyer can reproduce approved/refused synthetic actions,
inspect linked evidence and see where enforcement still depends on trusted
custody. No production risk reduction, adoption, exclusivity or acquisition
valuation is established by this demonstration.

## Proposed first workflow

One supplier-purchase approval path with fixed action fields and a destination
business-state version. Use synthetic or separately agreed partner-sandbox
records. Do not describe it as a live invoice payment or attach real credentials.
Buyer and ATG agree the problem, current alternative controls, allowed boundary,
test matrix and acceptance criteria before work begins.

## Discussion offer — unaccepted, scope-dependent

Starting proposal: a bounded technical evaluation from **£1,500**, subject to an
agreed quotation. This is not an established selling price, binding offer,
purchase commitment or evidence of demand. Include preparation, integration,
review/corrections, reporting, support and any assessor/hosting charges in the
scope before quoting. The buyer may fund independent review or infrastructure
separately; no such funding is assumed.

Deliverables: installation/provenance receipt, one fixed synthetic workflow,
positive/negative and recovery results, all failures retained, threat-model
discussion and a practical decision on a next integration. No guaranteed result,
production deployment, network certification, unlimited work or 24/7 support.

## Evaluation decision

Proceed only with a buyer who can name an authority-enforcement problem and a
technical owner for a bounded evaluation. Compare ATG with native policy, IAM,
approval and destination-idempotency controls; document overlap and extra value
instead of assuming a gap. Production remains NO-GO while common-owner state
editing, coherent clone replay and independent custody are unresolved.
