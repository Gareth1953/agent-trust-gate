# ATG — five-minute buyer checkpoint demonstration
**Draft for supervised synthetic evaluation. Not a live purchasing/payment or production system.**

## Minute-by-minute buyer journey
**0:00–1:00 — The problem:** An agent can propose an action that exceeds the authority originally granted, or reuse an old permission after local records are restored. ATG checks exact authority before a fictional effect.

**1:00–2:00 — One authorised fictional purchase:** Show the signed approval for the exact supplier, account, value, identity, tool, deadline and destination. Demonstrate that the protected writer verifies the submitted action *before* reserving permission in the separately running checkpoint. Show one synthetic transaction receipt.

**2:00–3:00 — Deliberate failed attacks:** Change the payee or amount; present the wrong client certificate; repeat the previously accepted action and restore writer-side records. Expected: no second fictional effect along the checkpointed protected path; invalid approval does not consume a legitimate reservation.

**3:00–4:00 — Shared allowance and outages:** Demonstrate the separately tested combined delegated-budget fixture (two sub-agents use £3,000 + £2,000 of one £5,000 ceiling; £2,500 overspend denied). Explicitly distinguish this combined OpenShell fixture from the new checkpointed route: the two features have NOT been proven end-to-end together in a buyer-controlled deployment. Stop the checkpoint and show UNKNOWN with no automatic retry.

**4:00–5:00 — Evidence and limits:** Show CI result, denied file/credential access checks, source hash and the intentionally retained successful direct-writer and whole-admin-restore counterexamples. Ask the buyer whether their existing effect system can enforce a compulsory non-bypassable route and whether an independent checkpoint custodian is available.
