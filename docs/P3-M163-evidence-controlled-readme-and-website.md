# P3-M163 Evidence-Controlled README and Website Guide

## Positioning

Agent Trust Gate™ is presented as the **Exact Action Trust Gateway for AI
agents**. It checks whether an exact proposed action remains within a
human-authorised mandate at the point where action authority would be granted.
It verifies declared authority, exact-action integrity, policy conditions and
lifecycle state; it does not decide commercial wisdom or outcome correctness.

Three connected layers reuse one authority core:

1. the Agent Integration Gateway exposes only `atg.evaluate_action` over local
   MCP stdio;
2. the Exact Action Trust Gateway applies canonical action, standing, mandate,
   policy, freshness and lifecycle checks; and
3. Business Assurance and Customer Trust add observational Shadow Mode,
   exposure/emergency/recovery controls and non-authorising evidence summaries.

## Evidence-controlled claims

`docs/P3-M163-public-claims-evidence-register.json` inventories material public
capability and numerical claims, their coverage classification and repository
evidence. `npm run validate:public-claims` validates the README and principal
site pages against the locked M162 bundle. It checks:

- coverage and ten-case outcome totals;
- synthetic-evidence labels and visible gaps;
- real package commands and resolving local links;
- Customer Trust Receipt and Shadow Mode non-authority language;
- the frozen synthetic-adapter boundary;
- required limitations and prohibited implications;
- the one-tool MCP boundary; and
- absence of analytics, tracking, telemetry and browser identifiers.

The M162 bundle remains authoritative. Public wording is a checked copy, not a
second source of truth.

## Website experience

The existing identity, navigation, colours and lightweight static architecture
are preserved. The home page now leads from mandate to exact action, verdict,
bounded authority and separate evidence. It includes the three connected
layers, the full ten-case table, Customer Trust Receipt explanation, exact
Coverage Map totals, selected labelled metrics, prominent limitations,
controlled-pilot terms and direct reviewer routes.

The shared stylesheet adds keyboard-visible focus, a responsive/focusable
table wrapper, non-colour verdict labels, coverage/metric cards, explicit
mobile/tablet breakpoints and the existing reduced-motion override. The shared
script now performs navigation and year display only. PostHog was removed;
there is no analytics or tracking path in the checked-in runtime.

## Controlled pilot wording

“Paid evaluation pilots starting from £1,500” remains an indicative,
scope-dependent posture. A pilot is bounded, local-first, evidence-led and
synthetic or non-production unless separately agreed and safely designed. The
buyer retains any real execution boundary. The existing human-reviewed email
route remains the only contact path; there is no form, checkout or payment
collection.

## Non-claims

The public material does not claim production readiness, customer deployment,
adoption or validation, certification, regulatory approval, guaranteed
compliance or safety, proven ROI or loss reduction, statistical significance,
distributed guarantees, real procurement/payment/settlement, business-outcome
correctness or real external-effect reconciliation.
