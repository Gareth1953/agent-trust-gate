# GitHub Reviewer Metadata Guidance

## Purpose

These are manual recommendations for improving repository discovery by
technical reviewers. P3-M151 does not call the GitHub API and does not run
`gh repo edit`.

## Recommended GitHub About description

`Local-only GatePass demonstrator for exact-action authorisation, refusal evidence, replay protection, and simulated execution receipts.`

This description is concise, fits GitHub's About description limit and avoids
claims of deployment, certification, live enforcement or production security.

## Recommended website

Use the project's existing static discovery URL:

`https://gareth1953.github.io/agent-trust-gate/`

It is a static discovery route, not a hosted API, live demo, contact form,
payment route or operational endpoint.
